# Themes baked into the AMIRA images by the overlay: compose.amira.yml sets the
# EXTRA_THEMES_FILE build arg to this file, which the Dockerfile reads in
# addition to _docker/extra-themes.txt (same omeka-s-cli syntax).
#
# Syntax: <omeka-s-cli URI> [target-directory]
#
# The URI is the published release archive, so the image gets the packaged theme
# rather than a clone of its development tree. scripts/update-module.sh rewrites
# the tag to the newest release.
#
# DRE-theme needs the explicit target whichever way it is fetched: omeka-s-cli
# names the directory after theme.ini's "name" field ("Africa Multiple — DRE" ->
# Africa_Multiple_____DRE), but the site rows in the database select the theme by
# directory name, so the build renames it back to DRE-theme.
https://github.com/AM-Digital-Research-Environment/DRE-theme/releases/download/v2.30.1/DRE-theme.zip DRE-theme
