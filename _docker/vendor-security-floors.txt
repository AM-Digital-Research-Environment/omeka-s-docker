# version. After modules are vendored, the build raises each listed package to
# the given constraint with a targeted `composer update` (the rest of the
# module's lock is left alone). A line is skipped when the module is absent or
# does not lock the package, so entries are safe to keep after upstream ships
# the fix — remove them once the module's own composer.lock reaches the floor.
#
# Syntax: <ModuleDir> <vendor/package>:<constraint>
